# دفتر المعاملات — النسخة 4

كل الملفات في مجلد واحد (بدون مجلدات فرعية). ارفعها جميعاً في جذر المستودع.

## الملفات
```
index.html        الصفحة الرئيسية (واجهة الدخول مدمجة فيها)
app.css           التنسيق والثيم الليلي/النهاري
main.js           نقطة البداية
firebase.js       الاتصال بقاعدة البيانات (مفاتيح Firebase)
state.js utils.js أدوات مشتركة
auth.js           الدخول والتسجيل المباشر وأمان الجلسة
ledger.js         الدفتر الرئيسي
statements.js     الملخص العام وكشف الأموال وكشوف القنوات
channels.js       القنوات والدفتر المشترك
exporter.js       تصدير CSV (قناة معينة / كل القنوات)
users.js          إدارة المستخدمين (للأدمن)
notifications.js  الإشعارات
backguard.js      حماية زر الرجوع
firestore.rules   قواعد الحماية (يجب نشرها)
```

## الرفع على GitHub
1. فك ضغط الملف.
2. في المستودع: Add file ← Upload files.
3. حدّد **كل الملفات** داخل المجلد واسحبها (وليس المجلد نفسه)، ثم Commit changes.
4. تُستبدل الملفات القديمة بنفس الأسماء وتُضاف الجديدة.
5. انتظر دقيقة ثم افتح الرابط وحدّث الصفحة بقوة (Ctrl+Shift+R).

## Firebase (يجب بعد كل تحديث للقواعد)
1. Firestore ← Rules: الصق محتوى `firestore.rules` ← Publish.
2. Authentication ← Sign-in method: فعّل Email/Password و Google.
3. Authentication ← Settings ← Authorized domains: أضف `suhipy0-tech.github.io` (النطاق فقط).

- [ ] نُشرت القواعد الجديدة
