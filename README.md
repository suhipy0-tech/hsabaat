# دفتر المعاملات — النسخة 3

## محتويات المشروع
```
index.html            الصفحة الرئيسية (تفتح منها كل الملفات)
css/app.css           التنسيق والثيم الليلي/النهاري
js/firebase.js        الاتصال بقاعدة البيانات (مفاتيح Firebase هنا)
js/state.js           الحالة المشتركة
js/utils.js           أدوات عامة
js/auth.js            الدخول والتسجيل وأمان الجلسة
js/ledger.js          الدفتر والمعاملات
js/users.js           إدارة المستخدمين (للأدمن)
js/channels.js        القنوات المشتركة بين المستخدمين
js/notifications.js   الإشعارات
js/main.js            نقطة البداية
firestore.rules       قواعد حماية قاعدة البيانات
```
**مهم:** يجب رفع المجلدات `css` و`js` كما هي بجانب `index.html`. لا تغيّر أسماءها ولا أماكنها.

## التشغيل المحلي للتجربة
الملفات تستخدم ES Modules، فلا تعمل بالنقر المزدوج على index.html.
افتح المجلد في VS Code وشغّل إضافة **Live Server** (Go Live).

## إعداد Firebase (مرة واحدة)
1. Authentication ← Sign-in method: فعّل **Email/Password** و**Google**.
2. Authentication ← Settings ← Authorized domains: أضف نطاق الموقع (مثل `اسمك.github.io`).
3. Firestore Database ← Rules: الصق محتوى `firestore.rules` ثم **Publish**.

## النشر على GitHub Pages
1. أنشئ مستودعاً Public، ثم Add file ← Upload files، واسحب **محتويات** المجلد (index.html و css و js) ثم Commit.
2. Settings ← Pages ← Branch: `main` ← Save.
3. الرابط: `https://اسمك.github.io/اسم-المستودع/`

## أول استخدام
1. افتح الرابط: تظهر شاشة **إعداد النظام**. أنشئ حساب المالك أولاً.
2. فعّل بريدك من الرسالة التي وصلتك (مطلوب لاستخدام القنوات).
3. المستخدمون الجدد: يسجلون بأنفسهم (الاسم الرباعي إجباري) ثم تظهر لك موافقتهم في الجرس.
